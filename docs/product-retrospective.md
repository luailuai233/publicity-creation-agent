# 产品复盘

本 Demo 的关键取舍是先证明“事实边界可控”的产品闭环，而不是用真实模型制造表面智能。结构化 Mock 让失败、重试、冲突和来源规则可重复验证；Provider 边界为以后接真实 API 保留空间。

最有价值的体验是把材料、事实、方法和正文分层：参考案例只能贡献写法，活动材料才能贡献事实；未确认或失去来源的事实不会进入策略和正文。导出前的确定性扫描继续兜底，AI 质量建议只是补充。

下一阶段应优先加入真实 Provider 的可观测性与成本控制、后台任务队列、图片 OCR/理解、项目级备份与导入导出。多人权限和线上部署应在存储与队列从单实例 SQLite 演进后再做。
