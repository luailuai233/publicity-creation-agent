# Demo 演示脚本

1. 运行 `scripts/setup.ps1` 和 `scripts/dev.ps1`，打开首页。
2. 点击“重置并打开完整 Demo”，确认活动资料与参考资料分区保存。
3. 在事实区选择 9:00 解决示例时间冲突；这是 Agent 允许人工介入的关键节点。
4. 从最近项目进入“宣传创作 Agent”，输入目标并只点击一次“开始自主创作”。
5. 观察当前计划和工具时间线：案例分析 → 三策略规划与自动推荐 → 内容生成 → 质量检查。
6. 打开策略页，确认三个方向实质不同且 Agent 已推荐一个；用户仍可覆盖。
7. 打开编辑页，查看推荐标题、大纲、正文和事实引用；无需逐步点击生成。
8. 打开系统检查，确认普通表达问题最多自动修订一次，事实问题不会被静默绕过。
9. 完成最终审核并导出 Markdown，在 `exports/` 查看成品。
10. 刷新 Agent 页面或重启服务，展示运行状态与成功步骤仍可恢复。
