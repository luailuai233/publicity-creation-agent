# 6–8 分钟面试演示脚本

1. 打开公开 Render 链接或本地 `http://127.0.0.1:8000`，先展示首页可以新建真实项目，也保留“载入示例项目”用于快速体验。
2. 进入“活动文件”，说明活动资料会形成带来源的事实；进入“事实确认”，展示普通事实默认通过、异常事实集中询问。
3. 进入“灵感收藏”，现场粘贴一段参考文章，或填写公开链接、上传截图；点击“分析表达方法”，强调参考内容不进入活动事实库。
4. 回到“宣传创作 Agent”，填写目标并点击一次“开始自主创作”。展示状态、当前阶段、下一动作和工具时间线，说明 Planner 会按项目快照决定下一工具。
5. Agent 到策略阶段必须暂停。通过顶部导航进入“编辑提案”，比较叙事主角、开头和结构，主动选择一个提案。
6. 回到 Agent 查看恢复与完成状态，再进入“推文日志”，查看标题、大纲、事实引用，演示局部改写、事实锁定和撤销。
7. 进入“发布检查”，展示硬风险不可确认绕过、软风险需记录说明；通过后导出 Markdown 或复制纯文本。
8. 最后展示仓库的 Provider 边界与 `render.yaml`：默认 Mock 免费跑全流程，配置 OpenAI-compatible 环境变量后即调用真实模型；公开免费站连续 15 分钟无访问会休眠，休眠、重新部署或实例重启都会清空数据。

建议收束语：这个项目不是固定点击脚本，而是“数据库快照 → 状态 Planner → 白名单工具 → 持久化结果 → 重新规划”的可暂停、可恢复单 Agent。
