# Demo 演示脚本

1. 运行 `scripts/setup.ps1` 和 `scripts/dev.ps1`，打开首页。
2. 点击“重置并打开完整 Demo”，确认三份材料均已解析。
3. 在事实时间线打开来源，选择 9:00 解决时间冲突。
4. 查看三个参考案例并逐一分析，确认只提炼方法、不混入活动事实。
5. 生成三个有明显差异的策略，选择“人物故事型”。
6. 生成标题和大纲，再生成正文；手工补一句，等待两秒观察自动保存。
7. 查看引用徽标和材料来源，运行质量检查。
8. 确认高风险提示（如有）后导出 Markdown，在 `exports/` 查看成品。
9. 可注入参考分析 schema 故障，演示旧结果保留、兄弟任务继续完成。
